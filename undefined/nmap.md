# Nmap 네트워크 열거

### 스캔 옵션



| **Nmap 옵션**          | **설명**                               |
| -------------------- | ------------------------------------ |
| `10.10.10.0/24`      | 대상 네트워크 범위.                          |
| `-sn`                | 포트 스캐닝을 비활성화합니다.                     |
| `-Pn`                | ICMP 에코 요청을 비활성화합니다.                 |
| `-n`                 | DNS 확인을 비활성화합니다.                     |
| `-PE`                | 대상에 대해 ICMP 에코 요청을 사용하여 핑 스캔을 수행합니다. |
| `--packet-trace`     | 보내고 받은 모든 패킷을 표시합니다.                 |
| `--reason`           | 특정 결과에 대한 이유를 표시합니다.                 |
| `--disable-arp-ping` | ARP Ping 요청을 비활성화합니다.                |
| `--top-ports=<num>`  | 가장 빈번하게 정의된 지정된 상위 포트를 검색합니다.        |
| `-p-`                | 모든 포트를 스캔합니다.                        |
| `-p22-110`           | 22에서 110 사이의 모든 포트를 스캔합니다.           |
| `-p22,25`            | 지정된 포트 22 및 25만 검사합니다.               |
| `-F`                 | 상위 100개 포트를 검색합니다.                   |
| `-sS`                | TCP SYN 스캔을 수행합니다.                   |
| `-sA`                | TCP ACK 스캔을 수행합니다.                   |
| `-sU`                | UDP 스캔을 수행합니다.                       |
| `-sV`                | 검색된 서비스의 버전을 검색합니다.                  |
| `-sC`                | "기본값"으로 분류된 스크립트로 스크립트 스캔을 수행합니다.    |
| `--script <script>`  | 지정된 스크립트를 사용하여 스크립트 스캔을 수행합니다.       |
| `-O`                 | OS 감지 스캔을 수행하여 대상의 OS를 확인합니다.        |
| `-A`                 | OS 감지, 서비스 감지 및 경로 추적 검사를 수행합니다.     |
| `-D RND:5`           | 대상을 스캔하는 데 사용될 무작위 디코이의 수를 설정합니다.    |
| `-e`                 | 스캔에 사용되는 네트워크 인터페이스를 지정합니다.          |
| `-S 10.10.10.200`    | 스캔의 소스 IP 주소를 지정합니다.                 |
| `-g`                 | 스캔의 소스 포트를 지정합니다.                    |
| `--dns-server <ns>`  | DNS 확인은 지정된 이름 서버를 사용하여 수행됩니다.       |

### 출력 옵션



| **Nmap 옵션**    | **설명**                                            |
| -------------- | ------------------------------------------------- |
| `-oA filename` | "filename"이라는 이름으로 시작하는 사용 가능한 모든 형식으로 결과를 저장합니다. |
| `-oN filename` | 결과를 "filename"이라는 이름으로 일반 형식으로 저장합니다.             |
| `-oG filename` | "filename"이라는 이름을 사용하여 결과를 "grepable" 형식으로 저장합니다. |
| `-oX filename` | "filename"이라는 이름으로 결과를 XML 형식으로 저장합니다.            |

### 성능 옵션



| **Nmap 옵션**                  | **설명**                         |
| ---------------------------- | ------------------------------ |
| `--max-retries <num>`        | 특정 포트의 스캔을 재시도하는 횟수를 설정합니다.    |
| `--stats-every=5s`           | 5초마다 스캔 상태를 표시합니다.             |
| `-v/-vv`                     | 스캔하는 동안 자세한 출력을 표시합니다.         |
| `--initial-rtt-timeout 50ms` | 지정된 시간 값을 초기 RTT 시간 초과로 설정합니다. |
| `--max-rtt-timeout 100ms`    | 지정된 시간 값을 최대 RTT 시간 초과로 설정합니다. |
| `--min-rate 300`             | 동시에 전송할 패킷 수를 설정합니다.           |
| `-T <0-5>`                   | 특정 타이밍 템플릿을 지정합니다.             |
