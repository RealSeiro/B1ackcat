# inetpub

`wwwroot` 폴더는 웹 서버의 루트 디렉토리로, 주로 웹 애플리케이션의 정적 파일과 리소스가 저장되는 위치입니다. 이 디렉토리는 웹 서버가 클라이언트 요청을 처리할 때 기본적으로 참조하는 디렉토리입니다. `wwwroot` 폴더에는 다음과 같은 항목들이 주로 포함됩니다:

1. **HTML 파일**:
   * 웹 페이지의 구조를 정의하는 HTML 파일들입니다.
   * 예: `index.html`, `about.html`
2. **CSS 파일**:
   * 웹 페이지의 스타일을 정의하는 CSS 파일들입니다.
   * 예: `styles.css`, `main.css`
3. **JavaScript 파일**:
   * 웹 페이지의 동작을 정의하는 JavaScript 파일들입니다.
   * 예: `app.js`, `main.js`
4. **이미지 파일**:
   * 웹 페이지에서 사용하는 이미지 파일들입니다.
   * 예: `.jpg`, `.png`, `.gif` 파일들
5. **폰트 파일**:
   * 웹 페이지에서 사용하는 폰트 파일들입니다.
   * 예: `.woff`, `.woff2`, `.ttf` 파일들
6. **라이브러리 및 프레임워크**:
   * jQuery, Bootstrap과 같은 외부 라이브러리 및 프레임워크 파일들입니다.
   * 예: `jquery.min.js`, `bootstrap.min.css`
7. **아이콘 파일**:
   * 웹 페이지의 파비콘과 같은 아이콘 파일들입니다.
   * 예: `favicon.ico`
8. **기타 정적 파일**:
   * PDF 문서나 기타 다운로드 가능한 파일들입니다.
   * 예: `document.pdf`



`gc`는 PowerShell에서 `Get-Content`의 약어로 사용됩니다. `Get-Content` 명령어는 파일의 내용을 읽어오는 데 사용됩니다. 따라서 `gc issues.php`는 `issues.php` 파일의 내용을 출력하는 명령어입니다.



ls가 막혔을 경우에는 gci를 사용하자!



쓰기 권한을 확인하고 싶은 경우 "echo test > login.php" 사용



```bash
gc issues.php
```
