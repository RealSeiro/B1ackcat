# Hashcat

```bash
hashcat -m 900 -a 0 <해시파일> <단어리스트>
```

여기서:

* `-m 900`은 MD4 해시 모드를 지정합니다.
* `<해시파일>`은 MD4 해시 값이 저장된 파일입니다.
* `<단어리스트>`는 해시를 크랙하기 위해 사용할 단어 리스트 파일입니다.

`-a` 옵션은 Hashcat에서 공격 모드(attack mode)를 지정하는 데 사용됩니다. Hashcat은 여러 가지 공격 모드를 제공하며, 각각 다른 방식으로 비밀번호를 크랙합니다. 여기 몇 가지 주요 공격 모드가 있습니다:

* `0` : Straight (직접 공격) - 이 모드는 일반적으로 단어 목록(wordlist) 또는 다른 사전 기반 공격에 사용됩니다.
* `1` : Combination (조합 공격) - 두 개의 단어 목록을 조합해서 공격합니다.
* `3` : Brute-force (무차별 대입 공격) - 가능한 모든 문자 조합을 시도합니다.
* `6` : Hybrid Wordlist + Mask (하이브리드 단어 목록 + 마스크) - 단어 목록에 기반한 값에 마스크(패턴)를 추가하여 공격합니다.
* `7` : Hybrid Mask + Wordlist (하이브리드 마스크 + 단어 목록) - 마스크에 기반한 값에 단어 목록을 추가하여 공격합니다.
